# Horizon Offer Network

مشروع مستقل لاختبار مزودي العروض والاستبيانات، ويُجهّز للنشر عبر GitHub وRailway. **لا يستخدم Supabase** ولا يتصل بقاعدة بيانات حاليًا.

## المزودون
- **CPAlead** — نقطة البداية للتحقق من إعدادات الناشر وجلب العروض لاحقًا.
- **CPAGrip** — إعداد رابط Offerwall.
- **TimeWall** — إعداد رابط Offerwall.
- **CPX Research** — إعداد رابط الاستبيانات.

## التشغيل
يتطلب Node.js حديثًا:

```bash
npm install
npm run build
npm start
```

للتطوير:
- `npm run dev` لتشغيل واجهة Vite.
- `npm run dev:server` لتشغيل خادم API.

## مسارات API الأولية
- `GET /health` — فحص صحة الخادم.
- `GET /api/providers` — قائمة المزودين وحالة التكامل الأولية.
- `GET /api/config-status` — يعرض هل متغيرات الإعداد موجودة دون كشف قيمها.

## متغيرات البيئة
استخدم `.env.example` كمرجع محلي. على Railway، أضف المتغيرات في إعدادات Variables. لا تضع مفاتيح الناشرين أو الأسرار داخل GitHub.

## الأمان والحدود الحالية
- أُضيف Helmet وCORS ومحدد معدل الطلبات لمسارات API.
- لم يتم تنفيذ postback أو التحقق من توقيعات التحويلات أو منع تكرار التحويلات بعد.
- لا تُمنح نقاط للمستخدمين في هذه المرحلة.
- المزودون غير متصلين بحسابات ناشرين فعلية حتى الآن.
- لا تعدّل أو تستورد قاعدة بيانات مشروع GainiRen أو `rewards-platform` ضمن هذا المختبر.
