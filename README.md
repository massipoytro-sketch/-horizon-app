# Horizon Offer Network

واجهة مستقلة أولية لشبكة العروض، بُنيت على قائمة الشركات التي عُثر عليها في مستودع `massipoytro-sketch/rewards-platform` وقاعدة بيانات Supabase المرتبطة به.

## الشركات المدرجة

- **CPAlead** — عروض CPA، جلب عروض، وتتبع التحويلات.
- **CPAGrip** — Offerwall عبر رابط الناشر، مع دالة postback.
- **TimeWall** — Offerwall واستبيانات، مع دوال جلب واستقبال تحويلات.
- **CPX Research** — رابط استبيانات ومعالجة تحويلات.

## الحالة الحالية

هذه النسخة تنشئ واجهة بيضاء بسيطة ومتجاوبة، وتعرض قائمة الشركات ومعلومات التكامل المعروفة. لم تُنقل مفاتيح الناشرين أو بيانات اعتماد Supabase، ولم يتم ربط التطبيق الجديد بقاعدة البيانات الأصلية أو اختبار جلب عروض مباشرة بعد. لذلك تظهر الشركات بحالة «يحتاج اختبار الاتصال» بدل الادعاء بأنها متصلة.

## التشغيل محليًا

يتطلب Node.js حديثًا:

```bash
npm install
npm run dev
```

## قواعد مهمة

- لا تضع مفاتيح API أو مفاتيح service-role في ملفات الواجهة أو المستودع.
- لا تنشئ تحويلات أو تضف نقاطًا من جهة المتصفح.
- يجب التحقق من توقيع postback ومنع تكرار التحويلات في جهة الخادم.
- لا تُجرِ تغييرات على قاعدة بيانات GainiRen الأصلية ضمن هذا المستودع المستقل.
